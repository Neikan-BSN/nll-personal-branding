nll-personal

nll-personal is a personal-use application operated by Jeff Browder. It saves selected Gmail messages and attachments for offline access, including Huddle messages, and creates encrypted archive backups in the owner's Google Drive.

The application requests only the Gmail permission gmail.readonly. This permits reading Gmail data; the application's configured selection rules determine which messages are archived. Those rules are not an account-wide permission restriction.

The archive covers selected categories: Huddles, starred messages, receipts and orders, bills and statements, school, nursing and work, and Sigma mail. It is not a full-mailbox backup.

The Gmail integration does not send, forward, modify, or delete Gmail messages. Existing Gmail originals are preserved.

This application is intended for the owner's personal use. There is no public signup service.
