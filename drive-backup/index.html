Mail Archive Drive Backup

Mail Archive Drive Backup is operated by Jeff Browder for personal use. It uploads encrypted offline mail archive packages and operational health receipts to the owner's existing Google Drive backup folder, and downloads backups for integrity and isolated restore checks.

This separate Drive connection requests https://www.googleapis.com/auth/drive, the same permission used by the existing backup connection. Google describes this permission as allowing the app to see, edit, create, and delete all Google Drive files. The configured backup folder limits the workflow's operations; it is not an account-wide OAuth permission restriction.

The configured workflow preserves existing backups and Gmail originals. This Drive app requests no Gmail permissions. The separate Gmail archive integration remains gmail.readonly. Hospital forwarding remains on hold.
