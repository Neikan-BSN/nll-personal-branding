nll-personal — Privacy Policy

nll-personal is operated by Jeff Browder for personal offline email archiving and Huddle retrieval.

Data accessed and purpose. The application uses Google's gmail.readonly permission to read selected message headers, bodies, and attachments. It uses this information to create offline copies, indexes, and backup and restore validation records. The permission allows reading Gmail data; the configured archive rules select the messages actually copied.

Storage and services. Message and attachment copies are stored on the owner's computer. Archive backups are encrypted before upload to the owner's Google Drive through a separate Drive connection. Operational receipts record archive status, counts, timestamps, and integrity results. OAuth credentials are stored separately using the configured secrets manager, Doppler. This Gmail integration does not request Drive permissions.

Use and sharing. Gmail data is used for the described personal archiving and Huddle retrieval functions. It is not sold or used for advertising. Public application information pages do not contain archived mail, attachments, credentials, or backup recovery keys.

Retention and deletion. Previously archived copies and existing backups are retained until the owner explicitly removes them. A message leaving the configured selection does not automatically delete its archived copy. Revoking Google access stops future authorized retrieval but does not delete copies already stored locally or in backups. Deleting archived copies is separate from deleting Gmail originals.

Control and contact. The owner can revoke this application's access in Google Account settings. For privacy, access, or deletion questions, contact jeff.browder@gmail.com.

This policy describes the configured personal archive workflow. It will be updated before materially different data uses are introduced.
